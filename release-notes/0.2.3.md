# CS2 Combiner 0.2.3

This release expands the supported main-texture sizes and refreshes the user
guide.

## Highlights

- Main maps may now be square 512, 1024, 2048, or 4096 pixel images.
- The same size rule is enforced during import and again before export.
- Every assigned main map must still match BaseColor exactly; textures are never
  resized.
- LOD2 inputs remain fixed at 512 × 512.
- The user guide now has opaque white text on blue controls and more compact
  controls in the Exporting section.

## Downloads

- `CS2-Combiner-0.2.3-macos.zip` — Apple Silicon, macOS 14 or later.
- `CS2-Combiner-0.2.3-windows-arm64.zip` — Windows 11 ARM and UTM on Apple
  Silicon.
- `CS2-Combiner-0.2.3-windows-x64.zip` — 64-bit Intel/AMD Windows and Windows
  11 ARM x64 emulation.
- `CS2-Combiner-User-Guide.pdf` — current illustrated user guide.

The Windows downloads are self-contained and do not require a separate .NET
installation.

The macOS build is ad-hoc signed and is not notarised.
