# CS2 Combiner 0.3.5

- Assigned Opacity maps now take precedence over embedded BaseColor alpha by default. Uncheck **Override BaseColor alpha** to use embedded alpha when both sources are present.
- LOD2 exports include a flat 512 × 512 normal map when no Normal input is assigned.
- The user guide explains both behaviours. The Windows executable identifies the app as a Cities: Skylines II tool.

## Downloads

- `CS2-Combiner-0.3.5-macos.zip` — Apple Silicon, macOS 14 or later.
- `CS2-Combiner-0.3.5-windows-arm64.zip` — Windows 11 ARM.
- `CS2-Combiner-0.3.5-windows-x64.zip` — 64-bit Intel/AMD Windows.
- `CS2-Combiner-User-Guide.pdf` — updated user guide.

The macOS app is ad-hoc signed and not notarised. The Windows apps are unsigned.
