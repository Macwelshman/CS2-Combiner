# CS2 Combiner 0.2.4

This release ensures every LOD2 texture set includes a valid normal map.

## Highlights

- LOD2 export now always writes `<asset>_LOD2_Normal.png`.
- When no LOD2 Normal input is assigned, the app creates a 512 x 512 flat
  OpenGL normal with RGBA values `128, 128, 255, 255`.
- Assigned LOD2 Normal maps remain supported and are exported unchanged.
- The LOD2 interface and user guide now explain the generated flat-normal
  fallback.
- macOS and Windows behavior remains aligned, with no resizing of supplied LOD2
  textures.

## Downloads

- `CS2-Combiner-0.2.4-macos.zip` - Apple Silicon, macOS 14 or later.
- `CS2-Combiner-0.2.4-windows-arm64.zip` - Windows 11 ARM and UTM on Apple
  Silicon.
- `CS2-Combiner-0.2.4-windows-x64.zip` - 64-bit Intel/AMD Windows and Windows
  11 ARM x64 emulation.
- `CS2-Combiner-User-Guide.pdf` - current illustrated user guide.

The Windows downloads are self-contained and do not require a separate .NET
installation.

The macOS build is ad-hoc signed and is not notarised.
