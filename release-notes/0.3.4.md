# CS2 Combiner 0.3.4

Normalise is now checked by default on macOS and Windows, including after clearing maps or removing the Normal map. You can still uncheck it when a Normal map is assigned.

Normalisation only affects the exported Normal texture; source maps remain unchanged. The user guide has been updated to describe the default.

## Downloads

- `CS2-Combiner-0.3.4-macos.zip` - Apple Silicon, macOS 14 or later.
- `CS2-Combiner-0.3.4-windows-arm64.zip` - Windows 11 ARM.
- `CS2-Combiner-0.3.4-windows-x64.zip` - 64-bit Intel/AMD Windows.
- `CS2-Combiner-User-Guide.pdf` - updated user guide.

Version 0.3.3 users can install this release through the in-app updater. Older versions require manual installation.

The macOS build is ad-hoc signed and not notarised. Windows builds are unsigned.
