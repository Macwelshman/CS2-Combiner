# CS2 Combiner 0.2.2

The first complete cross-platform release of CS2 Combiner.

## Highlights

- Native macOS app and self-contained Windows ARM64 and x64 builds.
- Drag-and-drop import for individual maps and complete folders.
- Manual drag-and-drop assignment on Main and LOD2 rows.
- Visually separated BaseColor, Control Mask, Mask Map, Surface, and LOD2
  sections.
- Main maps remain at their imported 1K, 2K, or 4K dimensions and are never
  resized.
- LOD2 maps remain at 512 × 512.
- Export-only OpenGL normal-map normalisation.
- Visible BaseColor-alpha and Opacity-map precedence with an explicit override.
- Default output to `CS2 Export` inside the BaseColor source folder.
- `CS2 Export` is excluded from subsequent source-folder scans.
- Existing destination files are listed before replacement.

## Downloads

- `CS2-Combiner-0.2.2-macos.zip` — Apple Silicon, macOS 14 or later.
- `CS2-Combiner-0.2.2-windows-arm64.zip` — Windows 11 ARM and UTM on Apple
  Silicon.
- `CS2-Combiner-0.2.2-windows-x64.zip` — 64-bit Intel/AMD Windows and Windows
  11 ARM x64 emulation.

The Windows downloads are self-contained and do not require a separate .NET
installation.

The macOS build is ad-hoc signed and is not notarised.
