# CS2 Combiner 0.3.3

This release adds dedicated Building, Surface, and Decal workflows on macOS and
Windows, together with secure in-app updates for future releases.

Users on 0.2.4 must install 0.3.3 manually once. In-app updating begins with
the next release because earlier versions do not contain the updater.

## Highlights

- Adds distinct **Building**, **Surface**, and **Decal** asset profiles.
- Exports the correct texture set and channel packing for each profile.
- Warns when a Surface texture folder is dropped while Building is selected.
- Keeps untested Decal maps inside a clearly labelled experimental section.
- Keeps the right-aligned asset selector visible while the map list scrolls.
- Improves export feedback and drag-and-drop highlighting.
- Brings the Windows selector, assigned-map ticks, and dialogs in line with the
  macOS interface.
- Adds automatic and manual update checks with verified downloads, staged
  replacement, and rollback on macOS and Windows.

## Downloads

- `CS2-Combiner-0.3.3-macos.zip` - Apple Silicon, macOS 14 or later.
- `CS2-Combiner-0.3.3-windows-arm64.zip` - Windows 11 ARM, including UTM on
  Apple Silicon Macs.
- `CS2-Combiner-0.3.3-windows-x64.zip` - 64-bit Intel/AMD Windows and x64
  emulation on Windows ARM.

The Windows builds are currently unsigned. Windows Smart App Control may block
them until the project adopts a trusted code-signing certificate or the files
gain sufficient reputation.
